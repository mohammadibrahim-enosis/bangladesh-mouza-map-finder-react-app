# Bangladesh Mouza Map Finder

A Next.js application for finding mouza maps across Bangladesh.

## Development

Install dependencies and start the development server:

```bash
corepack pnpm install
corepack pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available commands

- `corepack pnpm dev` starts the Next.js development server.
- `corepack pnpm build` creates a production build.
- `corepack pnpm start` serves the production build.
- `corepack pnpm lint` checks the code with ESLint.
